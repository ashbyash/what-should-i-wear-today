Key Changes

1

Hero Card = Temp + Score 통합

현재는 온도와 점수가 별도 카드에 멀리 떨어져 있음. 하나로 합치면 첫 눈에 핵심 정보 파악 가능. LocationHeader도 여기에 흡수.

2

Conditions Row = PM2.5 + UV + Humidity 한 줄

DustCard/UvCard를 별도 카드 대신 컴팩트한 한 줄 뱃지로. 습도도 추가. 공간 절약 + 한눈에 스캔 가능.

3

Keep Current Structure
